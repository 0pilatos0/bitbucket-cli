Get started Installation

Requires Bun 1.0+ · npm: @pilatos/bitbucket-cli

$ npm install -g @pilatos/bitbucket-cli
$ bb auth login # authenticate
$ bb repo clone workspace/repo
$ bb pr create -t "My awesome feature"
$ bb pr list
✓ 3 open pull requests

What can you do?

Sixteen command groups over the full Bitbucket Cloud 2.0 API — generated from a pinned OpenAPI spec, so types never drift.

Repository management

Clone, create, list, view, and delete repositories.

bb repo clone workspace/repo
bb repo list -w myworkspace

Pull requests

Full PR lifecycle — create, review, approve, merge.

bb pr approve 42
bb pr merge 42 --strategy squash

Code review

View diffs, checkout PR branches, inspect checks.

bb pr diff 42
bb pr checkout 42

CI/CD pipelines

Trigger, inspect, and stop Bitbucket Pipelines.

bb pipeline run --branch main
bb pipeline logs 42

Workspaces & projects

Find the workspaces you belong to and the projects inside them.

bb workspace list
bb project view PROJ

Issues, snippets & commits

Track issues, share snippets, read history, publish build statuses.

bb issue list --state open
bb status set abc1234 --state SUCCESSFUL

Jump to the web UI

Open Bitbucket pages — PRs, files, commits, settings — in your browser.

bb browse src/cli.ts:20
bb browse --pipelines

Scripting & automation

Every command speaks JSON. --json projects a field list, --jq filters in-process.

bb pr list --json id,title
bb pr list --jq '.[0].title'

Raw API access

Reach any Bitbucket 2.0 endpoint not yet wrapped by a typed command.

bb api /user
bb api /repositories/… --paginate

PR workflows

Everything around pull requests, from opening to merging — including comments and reviewers.

Create, edit, and view

Open a PR, change its title or description, list PRs, inspect one.

Review and merge

Approve, decline, mark drafts ready, and merge with explicit strategy control.

Diff and checkout

Review patch output, fetch PR branches locally, and open browser diffs.

Activity and checks

Inspect activity history and CI/build status before approving or merging.

Review comments

List, add, reply to, resolve, and delete general or inline review comments.

Reviewers

Add and remove reviewers — idempotent, with sensible no-ops.
