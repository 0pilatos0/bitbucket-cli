Description

Pipeline logs currently require opening the browser and waiting for the page. This adds a bb pipeline logs command that streams the log endpoint directly to stdout.

Output is plain text by default and JSON (--json) for tooling — consistent with every other command in the CLI.

async run() {
const res = await fetchLogs(id)
print(res.text)
const stream = await api.stream(
`/pipelines/${id}/logs`,
{ follow: this.flag('follow') }
)
for await (const chunk of stream) {
process.stdout.write(chunk)
}
}
