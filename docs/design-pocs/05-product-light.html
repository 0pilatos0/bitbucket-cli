Capabilities

What it covers

Every command group wraps the Bitbucket Cloud 2.0 REST API, generated from a pinned OpenAPI spec so types never drift.

Pull requests

Create, review, approve, and merge — with explicit merge-strategy control and reviewer management.

bb pr merge 42 --strategy squash

Repositories

Clone, create, list, view, and delete repositories across every workspace you belong to.

bb repo clone workspace/repo

Pipelines

Trigger, inspect, and stop Bitbucket Pipelines. Read logs without opening the browser.

bb pipeline run --branch main

Scripting first-class

Field projection with --json and in-process filtering with --jq — no external jq binary.

bb pr list --json id,title --jq '.[0].title'

Web UI shortcuts

Open any Bitbucket page — PRs, files at a line, commits, pipeline settings — in one command.

bb browse src/cli.ts:20

Raw API access

Reach any 2.0 endpoint that isn't wrapped yet, with auth, pagination, and form bodies handled.

bb api /repositories/{ws}/{repo}/pullrequests
For automation

Designed to be scripted against

Text output is for people. When stdout is a machine, bb changes shape instead of making you parse prose.

  • Projected JSON. --json id,title returns a flat array with exactly those keys — dotted paths keep their full name.
  • No jq dependency. --jq filters in-process. Works in minimal CI containers.
  • Documented exit codes and stable error codes — failures are detectable, not just visible.
release.shbash
# wait for CI, then merge when green
if bb pipeline status --branch main --json state \
    | grep -q SUCCESSFUL; then
  bb pr merge "$PR_ID" --strategy squash
  bb status set "$SHA" --key BB-DEPLOY \
      --state SUCCESSFUL
fi

# → ✓ Merged pull request #47 into main
