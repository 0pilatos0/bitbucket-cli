Capabilities

Everything, without leaving the terminal.

Sixteen command groups over the full Bitbucket Cloud API — typed, scriptable, fast.

⑂

Pull requests

Full PR lifecycle — create, review, approve, and merge with explicit strategy control.

bb pr merge 42 --strategy squash
⎇

Repositories

Clone, create, list, view and delete repos across every workspace you belong to.

bb repo clone workspace/repo
◈

Pipelines

Trigger, inspect, and stop Bitbucket Pipelines. Stream logs straight to your shell.

bb pipeline run --branch main
⌗

JSON everywhere

Every command speaks JSON. Project fields and filter in-process — no jq binary needed.

bb pr list --json id,title --jq '.[0].title'
↗

Jump to the web

Open any Bitbucket page — PRs, files, commits, settings — directly in your browser.

bb browse src/cli.ts:20
✦

Raw API access

Reach any Bitbucket 2.0 endpoint not yet wrapped by a typed command.

bb api /repositories/{ws}/{repo}/pullrequests
