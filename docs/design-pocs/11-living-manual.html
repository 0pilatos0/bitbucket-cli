Automation

Output that scripts can trust

Text output is for people. When stdout is a machine, bb changes shape instead of making you parse prose.

Field projection

--json accepts a field list. Dotted paths keep their full name as the key. You get a flat array with exactly the fields you asked for — nothing else to diff against next release.

$ bb pr list --json id,title,author.display_name
[
{"id":47,"title":"feat: streaming logs","author.display_name":"Paul"}
]

In-process jq

--jq evaluates inside the CLI process. No jq binary, no shell pipe, works in the most minimal CI container you can build.

$ bb pr list --jq '.[0].title'
"feat: streaming pipeline logs"
 
$ bb api /repositories/acme/core-api/pullrequests --paginate --jq 'length'
47

Exit codes you can branch on

Every failure has a documented, stable exit code. CI gates on bb pipeline status without scraping text.

$ bb pipeline status --branch main
● IN_PROGRESS build #313 · 4m 12s
$ echo $?
2
