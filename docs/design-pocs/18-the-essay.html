Bitbucket Cloud, from the command line.

bb wraps the Bitbucket Cloud 2.0 REST API in sixteen command groups — repositories, pull requests, pipelines, issues, snippets, and a raw escape hatch for everything else. If you know GitHub's gh, the shape is deliberately familiar.

Install it globally with your package manager of choice. The only prerequisite is the Bun runtime, version 1.0 or later.

npmpnpmbun
npm install -g @pilatos/bitbucket-cli

Authentication happens once. bb auth login stores an app password in your platform's config directory with 0600 permissions, and from then on most commands resolve their workspace and repository from the git remote of whatever checkout you're standing in.

example session
$ bb pr list --state OPEN
#47   feat: streaming pipeline logs   OPEN
#46   fix: retry on 429 rate limits   OPEN

$ bb pr merge 47 --strategy squash
✓ Merged pull request #47 into main (squash)

$ bb pipeline run --branch main
✓ Queued build #313

For scripts and CI, text output is the wrong medium. Every command therefore speaks JSON when asked — and rather than making you shell out to jq, filtering runs inside the CLI process.
