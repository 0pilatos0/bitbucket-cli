bb is a single authenticated client in front of the Bitbucket Cloud 2.0 REST API. Terminal, scripts, CI — every surface speaks the same command language, with --json on everything.

Surfaces

Three ways in, one client

Humans read text output. Machines read JSON. Everyone gets the same auth, same flags, same exit codes.

Humans

Typed commands

Short groups, repository context from your git remote, output made for reading.

bb pr list --state OPEN
Scripts

Projected JSON

Field lists and in-process jq. A flat array, exactly the keys you named.

bb pr list --json id,title --jq '.[0].id'
Agents

Tool schemas

Every command documented as a callable tool for coding agents and loops.

bb api /user --jq '.display_name'
