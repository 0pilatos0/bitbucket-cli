Feature matrix

Asymmetric on purpose — cell size maps to how often you'll reach for it.

A1 Primary surface

Pull requests, end to end

Open, review, approve, and merge without leaving the shell. Merge strategies are explicit flags, never config. Reviewers, comments, and checks are all first-class subcommands.

# merge with intent, not defaults
$ bb pr merge 42 --strategy squash
✓ Merged pull request #42 into main (squash)
A5 Automation

JSON everywhere

100% of commands project fields with --json.

B5 Automation
