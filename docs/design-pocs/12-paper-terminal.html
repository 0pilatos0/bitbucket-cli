A command line interface for Bitbucket Cloud

bb wraps the Bitbucket Cloud 2.0 API in sixteen composable command groups. Repositories, pull requests, pipelines — driven from your shell, with JSON output on every command. Built by a community, for the terminal-first.

Installation

The CLI ships as a single package on npm and installs globally with your package manager of choice. Authentication happens once: bb auth login stores an app password in your platform's config directory with 0600 permissions.

From then on, most commands resolve their workspace and repository from the git remote of your current checkout — bb pr list is enough. Explicit flags always win when you need to target another repository.

$ npm install -g @pilatos/bitbucket-cli
$ pnpm add -g @pilatos/bitbucket-cli
$ bun install -g @pilatos/bitbucket-cli
ii.

An index of capabilities

ii.1

Repositories

Clone, create, list, view, and delete.

bb repo clone ws/repo
ii.2

Pull requests

Full lifecycle, explicit merge strategies.

bb pr merge 42 --strategy squash
ii.3

Code review

Diffs, branch checkout, CI checks.

bb pr diff 42
ii.4

Pipelines

Trigger, watch, stop; stream logs.

bb pipeline run --branch main
ii.5

Scripting

JSON projection and in-process jq.

bb pr list --json id,title
ii.6

Raw API

Any 2.0 endpoint, paginated.

bb api /repositories/… --paginate
ii.7

Web UI bridges

Open PRs, files, commits in the browser.

bb browse src/cli.ts:20
ii.8

Issues & snippets

Track work, share files, publish statuses.

bb issue list --state open
