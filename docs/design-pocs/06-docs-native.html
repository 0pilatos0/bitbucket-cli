Introduction

bb is an open-source command line interface for Bitbucket Cloud. It wraps the Bitbucket 2.0 REST API in composable commands with consistent flags, exit codes, and JSON output.

The design follows gh, the GitHub CLI: short command groups, repository context detected from your git remote, and output modes that switch between human-readable text and machine-readable JSON. It is built on Bun, written in TypeScript, and distributed on npm as @pilatos/bitbucket-cli.

Installation

bb requires the Bun runtime, version 1.0 or later. Install globally with your package manager of choice:

shellnpm · pnpm · bun
# npm
npm install -g @pilatos/bitbucket-cli

# pnpm
pnpm add -g @pilatos/bitbucket-cli

Quick start

Authenticate once with a Bitbucket app password, then run commands from any repository checkout:

shellexample session
# authenticate (stores credentials in your OS config dir)
$ bb auth login

# run from inside a repository — workspace and repo are detected
$ bb pr list --state OPEN
ID    TITLE                           BRANCH            STATE
#47   feat: streaming pipeline logs   feat/log-stream   OPEN

# or target a repository explicitly
$ bb pr list -w acme -r core-api --state OPEN
ⓘ Repository context. When you run bb inside a git checkout, the workspace and repository are resolved from the origin remote. Explicit flags always win. See repository context.

Output modes

Every command supports --json. Pass a field list to project exactly the keys you need, and --jq to filter in-process — no external jq binary required:

shellJSON output
$ bb pr list --json id,title
[{"id":47,"title":"feat: streaming pipeline logs"}, …]

$ bb pr list --json id,title --jq '.[0].title'
"feat: streaming pipeline logs"

FlagDescription
