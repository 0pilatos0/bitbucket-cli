bb --help # what can it do?
01
bb repo clone ws/repo

Clone, create, list, view and delete repositories across every workspace you belong to.

02
bb pr merge 42

Full PR lifecycle — create, review, approve and merge with explicit strategy control.

03
bb pr diff 42

View diffs, checkout PR branches locally, inspect CI checks before you approve.

04
bb pipeline run

Trigger, watch and stop Bitbucket Pipelines. Stream logs straight to your terminal.

05
bb pr list --json --jq

Every command speaks JSON. Project fields, filter in-process — no jq binary needed.

06
bb api /user

Raw access to any Bitbucket 2.0 endpoint not yet wrapped by a typed command.
