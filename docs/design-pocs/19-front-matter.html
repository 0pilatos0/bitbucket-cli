A command line interface for Bitbucket Cloud — unofficial, community edition, MIT

The terminal manual for Bitbucket Cloud.

bb wraps the Bitbucket Cloud 2.0 REST API in sixteen command groups — repositories, pull requests, pipelines, issues, and a raw escape hatch for everything else. Every command outputs JSON: --json projects fields, --jq filters in-process. One binary, one config file, no other dependencies.

$ npm install -g @pilatos/bitbucket-cli requires Bun 1.0+
